# Download independente do projeto completo

[Baixar ZIP pela Vercel](https://harmos-conecta.vercel.app/downloads/Harmos_Conecta_Projeto_Completo_2026-11-23.zip)

[Alternativa pelo GitHub](https://raw.githubusercontent.com/webluxfloripa-lab/Harmos-Academia-ia-WhatsApp-/main/public/downloads/Harmos_Conecta_Projeto_Completo_2026-11-23.zip)

O mesmo arquivo inclui código-fonte, licença MIT do código original, configurações Vercel, frontend publicado, estrutura e fotografia dos dados de negócio do Supabase, regras de acesso, script do widget e instruções de restauração. As tabelas de negócio, Auth e Storage estavam vazias na fotografia de 23/11/2026.

Credenciais, sessões, verificadores de segredos, allowlist administrativa e estado temporário de rate limiting não integram o ZIP público. Os segredos devem ser configurados novamente pelo operador de uma instalação nova.

A fonte do pacote parte do commit 4cd2df279283bdcd29bce6c98470bf24c945acf0. A publicação capturada partia de 37f244c455fccd0d470c4aa014814d03e0e17464; apenas três documentos diferiam, sem diferença no código executado. Foram adicionados auxiliares de restauração, servidor Node opcional e licenças.

Confira o SHA256 no arquivo .sha256 ao lado do ZIP e os hashes internos em SHA256SUMS.txt.
